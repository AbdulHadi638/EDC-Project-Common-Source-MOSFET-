# EDC-Project-Common-Source-MOSFET-
Designed and fabricated a Common Source MOSFET amplifier using a BS170 MOSFET on a custom PCB. Performed PCB etching, drilling, soldering, and circuit testing. Achieved a stable gain of 34 V/V, verified simulation results with practical measurements, and observed the expected 180° phase shift through bias tuning and signal optimization.
